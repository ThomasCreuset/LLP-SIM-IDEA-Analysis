# How to use this github repository

## Get the github

- Create a folder `FOLDER`
- Move to the folder : `cd FOLDER_PATH`
- Run `git clone https://github.com/ThomasCreuset/LLP-SIM-IDEA-Analysis`

## Structure

### Background

To process background look at the instructions in the `Background/` folder.

### Signal

To process signal look at the instructions in the `Signal/` folder.

### Data

Most proced data end up in the `Data/` folder. The only exception are madGraph files who stay in the `Signal/mc-pythia-main/` folder.
